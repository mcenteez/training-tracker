## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Local test personas

To test roles without creating Clerk accounts, seed the dedicated local organization and start the development server in local-auth mode:

```bash
npm run dev:local
```

Open [http://localhost:3000/dev/auth](http://localhost:3000/dev/auth) and choose the Owner, Basketball Team Manager, Basketball Athlete, or Viewer persona. Local mode uses an HTTP-only allowlisted persona cookie; organization and team permissions still come from database memberships. `AUTH_MODE=local` is rejected in production.

Run the same role scenarios in Playwright with:

```bash
npm run test:e2e
```

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
